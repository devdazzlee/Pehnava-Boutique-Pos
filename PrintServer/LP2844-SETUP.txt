Pehnava POS — Eltron / UPS LP 2844 label printer (EPL)
=========================================================

Your printer: UPS LP2844PSAT, Eltron, EPL, 203 DPI, Made in USA.

Label stock (Pehnava default):
  Width:  50 mm (1.97 in) — ~5 cm on the roll
  Height: 25 mm (0.98 in) — ~2.5 cm feed direction
  Gap:    3 mm between labels
  Across: 1 label

Windows setup (client laptop with Print Server)
------------------------------------------------
1. Connect USB and power on (green ready light on feed button).

2. Install driver — use Zebra's legacy Eltron LP 2844 driver in EPL mode, OR
   "Eltron LP 2844" from Windows Update. Queue name often contains "(EPL)".

3. Printer properties → Preferences:
   - Paper / Stock: Custom 50 × 25 mm (or 2.00 × 1.00 in)
   - Gap / media: 3 mm between labels
   - Print speed: 4 ips; Darkness: 7–8

4. Run Print Server as Administrator once: SETUP-CLIENT-LAPTOP.bat

5. In POS → Printer Settings → Barcode printer → Test Print

6. In Barcode Generator, select **50 × 25 mm (2 × 1 in, 3 mm gap)**.

How Pehnava prints
------------------
EPL raw print: 50×25 mm @ 203 DPI ≈ 400×200 dots, Q gap ≈ 24 dots (3 mm).
Compact layout: title, weight/price, PKG/EXP, Code 128 barcode.

If labels do not print:
- Print Server: http://localhost:3001/health
- Windows queue name must match Printer Settings
- Calibrate media if feed skips or misaligns
